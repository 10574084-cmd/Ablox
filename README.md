# Ablox

Ablox is an independent fan-made browser game hub featuring original, lightweight 3D experiences created for this project.

## Included experiences
- **Sky Obby 3D** — jump between floating platforms and reach the finish.
- **Coin Rush City** — explore a small 3D city and collect coins.
- **Neon Run 3D** — dodge obstacles on a neon runner track.

## Run locally
Open `index.html` in a modern browser, or serve this folder using any static HTTP server.

## GitHub Pages
This is a static website. Publish the repository root (`/`) from the `main` branch in GitHub Pages.

## Controls
- **WASD / Arrow keys** — move
- **Space** — jump
- **Escape** — pause
- Touch controls appear on smaller screens.

## Technology
Vanilla HTML, CSS, JavaScript and the Canvas 2D API. The 3D scenes use a small perspective projection renderer written for Ablox, with no game-engine dependency. Favorites and best scores are stored locally in the browser.

## Project note
Ablox is a fan-made, independent project and is not affiliated with, endorsed by, or sponsored by Roblox Corporation. All game names, scenes, interface elements and code in this repository are original Ablox content.
